# Docker Compose Practice W5

## Cau truc
- `part-1-commands.md`: Lenh Docker Compose co ban.
- `part-2/`: 15 bai Docker Compose file co ban.
- `part-3/`: 10 bai tap nang cao.

## Cach chay nhanh
1. Di chuyen vao thu muc bai can chay.
2. Chay `docker compose config` de kiem tra file.
3. Chay `docker compose up -d` hoac `docker compose up -d --build`.
4. Kiem tra log: `docker compose logs -f`.
5. Don dep: `docker compose down -v`.
